Three roles, three business models

In Week 1 you declare a role. It decides what you build, how you earn, and which unlock ladder you climb for the rest of the season.

What you build

A WebSocket server with a central limit order book. Price-time priority matching, order acks, book snapshots, portfolio updates — the venue everyone else connects to.

How you earn

Transaction fees. Under the maker/taker model you collect 0.0015 from the aggressor and pay 0.0010 back to the resting order; the difference is yours. Set fees too high and flow leaves for another venue.

Your ladder

  • L1 basic CLOB, flat fee
  • L2 portfolios & leaderboard
  • L3 maker/taker fees
  • L4 circuit breakers (LULD)
  • L5 rate limits & order types
  • L6 full analytics dashboard

What you build

A market maker. Poll Yahoo Finance on a background thread, derive a fair value, and continuously post two-sided quotes on the exchange — requoting whenever the reference price moves.

How you earn

The spread: (ask_fill - bid_fill) × qty / 2, plus the maker rebate. Your enemy is inventory risk — a one-sided market leaves you holding the position while the price runs against you.

Your ladder

  • L1 static spread quotes
  • L2 requote on price move
  • L3 vol-adjusted spread
  • L4 inventory skew
  • L5 toxic-flow detection
  • L6 multi-venue routing

What you build

An algorithmic bot. Subclass arena.Trader, implement on_tick(market, portfolio), return a Signal — or None. The SDK handles sockets, auth and reconnection.

How you earn

Realised P&L on closed positions plus the mark-to-market on open ones, net of fees. Every crossing trade pays the spread and the taker fee, so an edge has to beat both before it is an edge.

Your ladder

  • L1 connect & place orders
  • L2 live portfolio tracking
  • L3 a real signal
  • L4 risk management
  • L5 execution optimisation
  • L6 ML strategies

Smoke test: RED · 0 of 6 steps

If something is red

ConnectionRefused when the bot connects

The exchange server is not running yet — the instructor starts it first.

Check EXCHANGE_HOST and EXCHANGE_PORT in your .env.

pydantic import error

The arena requires pydantic v2 and will not run against v1.

Re-run make install in a clean 3.11 venv; never mix v1 and v2.

API key not found on Windows

export is not persistent on Windows shells.

Copy .env.example to .env and load it with python-dotenv. Never commit .env.

yfinance rate-limited

Yahoo throttles aggressive polling; a tight yf.download() loop will get you blocked.

Respect YAHOO_POLL_INTERVAL (5s default); the broker SDK already backs off.

Bot missing from the teacher dashboard

The handshake was accepted but under a team the instructor does not know.

Your TEAM_ID (and ARENA_TOKEN) must match the registered roster exactly.
